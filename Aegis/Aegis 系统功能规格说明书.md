# Aegis 系统功能规格说明书

## 1. 项目背景与目标
Aegis（宙斯盾）是一款专为小型团队和个人开发者设计的轻量级 Web 漏洞检测系统（DAST）。其核心目标是在保证目标业务不受影响的前提下，通过模拟攻击流量自动化地识别 Web 应用中的安全风险。

## 2. 核心功能模块

### 2.1 扫描管理模块
- **任务创建**：支持输入目标 URL、选择扫描策略（快速/全面）及配置登录凭据。
- **自动登录**：集成 Playwright 模拟浏览器行为，支持表单登录及 Cookie 注入，确保扫描覆盖授权区域。
- **实时监控**：通过 WebSocket 实时推送扫描进度、当前探测 URL 及发现的漏洞摘要。

### 2.2 漏洞检测引擎 (YAML 驱动)
- **插件化检测**：采用类似 Nuclei 的 YAML 模板引擎，支持自定义探测逻辑。
- **无害化 Payload**：内置 Payload 仅用于验证漏洞存在（如 `sleep` 探测），严禁破坏性指令。
- **SPA 支持**：深度解析现代前端框架（React/Vue）生成的动态内容。

### 2.3 漏洞审计与报告
- **证据链展示**：记录并展示触发漏洞的完整 HTTP 请求与响应报文。
- **多格式导出**：支持一键生成 JSON、HTML、Markdown 及 PDF 格式的专业安全报告。
- **修复建议**：为每个发现的漏洞提供针对性的修复方案。

## 3. 业务流程
1. **配置阶段**：用户输入目标并配置登录信息。
2. **爬取阶段**：系统自动发现页面链接及 API 接口。
3. **探测阶段**：根据发现的输入点，匹配并执行 YAML 插件。
4. **归档阶段**：汇总结果，生成多格式报告供下载。

## 4. 非功能性需求
- **安全性**：系统自身 API 具备鉴权机制，扫描节点具备环境隔离。
- **性能**：单机支持 1-3 个并发扫描任务，QPS 可配置。
- **部署**：支持 Docker Compose 一键式快速部署。
