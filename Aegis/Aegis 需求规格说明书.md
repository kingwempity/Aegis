# Aegis 需求规格说明书

## 1. 项目概述
Aegis（宙斯盾）是一款轻量级、高性能的 Web 应用程序漏洞检测系统（DAST）。它旨在通过模拟攻击流量，在不破坏目标业务的前提下，自动化地发现 Web 应用中的安全漏洞。

## 2. 核心目标
- **精准探测**：支持现代单页应用（SPA），具备高检出率和低误报率。
- **无害化扫描**：严格遵循非侵入式原则，仅验证漏洞存在，不执行破坏性操作。
- **易用性**：提供直观的 Web 界面，支持一键启动扫描和多格式报告导出。
- **可扩展性**：采用 YAML 驱动的插件系统，方便快速集成新的检测逻辑。

## 3. 功能需求

### 3.1 扫描引擎
- **智能爬虫**：支持静态链接提取及基于 Playwright 的动态页面渲染爬取。
- **自动登录**：支持手动注入 Cookie 或通过预设凭据模拟登录以维持扫描会话。
- **漏洞检测**：支持 SQL 注入、XSS、目录遍历、配置泄露等 OWASP Top 10 漏洞检测。
- **频率控制**：支持自定义 QPS 限制，防止对目标服务器造成压力。

### 3.2 任务管理
- **任务调度**：支持创建、暂停、停止和重启扫描任务。
- **实时监控**：前端实时展示扫描进度、当前 URL 及已发现的漏洞统计。

### 3.3 报告生成
- **多格式支持**：支持生成 JSON、HTML、Markdown 及 PDF 格式的报告。
- **证据链展示**：报告中必须包含触发漏洞的 Payload 及原始 HTTP 请求/响应报文。

## 4. 非功能需求
- **数据规模**：定位为小型数据规模，优化单机运行性能。
- **安全性**：系统自身 API 需具备完善的鉴权机制。
- **部署**：支持 Docker Compose 一键部署。
