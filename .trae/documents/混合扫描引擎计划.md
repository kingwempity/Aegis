# 混合扫描引擎计划

## 🎯 目标

结合 `ScannerEngine`(插件驱动,高可靠性)和 `AttackSimulator`(LLM 驱动,高智能性)的优势,实现**两阶段混合扫描**,大幅提高漏洞检测命中率。

## 📊 当前问题

| 引擎 | 优势 | 劣势 |
|------|------|------|
| `ScannerEngine` | ✅ 确定性执行,快速可靠 | ❌ 只能检测预定义插件 |
| `AttackSimulator` | ✅ LLM 智能探索,能发现未知漏洞 | ❌ 依赖 LLM 输出质量,速度慢 |

## 🔧 方案设计

### 两阶段混合扫描架构

```
阶段1: 快速扫描 (ScannerEngine)
  ↓ 发现已知漏洞
  ↓ 收集目标信息(框架/技术/路径)
  ↓
阶段2: 智能探索 (AttackSimulator)
  ↓ 利用阶段1的信息作为上下文
  ↓ LLM 针对性探索未知漏洞
  ↓
返回合并结果
```

### 工作流程

```
1. 启动 ScannerEngine 快速扫描
   - 加载所有 .yaml 插件
   - 批量执行预定义 payload
   - 记录发现的漏洞
   - 提取侦察信息(框架/版本/入口点)

2. 将阶段1结果传递给 AttackSimulator
   - detected_frameworks
   - framework_versions
   - discovered_entry_points
   - already_found_vulns (避免重复)

3. AttackSimulator 智能探索
   - 基于阶段1信息生成路径建议
   - LLM 探索插件未覆盖的路径
   - 补充发现未知漏洞

4. 合并结果返回
```

## 📝 实现步骤

### Step 1: 创建混合扫描引擎类

**文件**: `scanner/engine/hybrid_engine.py`

```python
class HybridScannerEngine:
    """混合扫描引擎: 结合 ScannerEngine 和 AttackSimulator"""
    
    async def run(self) -> List[Dict]:
        # 阶段1: 快速扫描
        scanner = ScannerEngine(...)
        fast_vulns = await scanner.run()
        recon_info = scanner.get_framework_detection_result()
        
        # 阶段2: 智能探索 (仅当有侦察信息时)
        if recon_info['detected_frameworks']:
            simulator = AttackSimulator(...)
            simulator.set_recon_context(recon_info)  # 传递侦察结果
            smart_vulns = await simulator.run_simulation()
            
            # 合并去重
            return self._merge_and_deduplicate(fast_vulns, smart_vulns)
        else:
            return fast_vulns
```

### Step 2: 修改 AttackSimulator 接收上下文

**文件**: `scanner/engine/simulator.py`

```python
def set_recon_context(self, recon_info: Dict):
    """设置侦察阶段信息,供 LLM 决策使用"""
    self.context["detected_frameworks"] = recon_info.get('detected_frameworks', [])
    self.context["tech_versions"] = recon_info.get('framework_versions', {})
    self.context["entry_points"] = recon_info.get('entry_points', [])
    self.context["already_found_vulns"] = recon_info.get('found_vulns', [])
```

### Step 5: 结果合并去重

**文件**: `scanner/engine/hybrid_engine.py`

```python
def _merge_and_deduplicate(self, fast_vulns, smart_vulns):
    """合并并去重漏洞结果"""
    seen_urls = set()
    merged = []
    
    for vuln in fast_vulns + smart_vulns:
        key = (vuln['url'], vuln['vuln_name'])
        if key not in seen_urls:
            seen_urls.add(key)
            merged.append(vuln)
    
    return merged
```
